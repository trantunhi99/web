Chapter 01

It started with a question

Can AI see what pathologists see — and bring that power to every researcher's browser?

Featured Build

Interactive Web Platform for Loki — Whole-Slide Image Analysis

📄 Nature Methods (2025) — Co-author

Engineering a full-stack interactive platform on top of Loki, a published AI framework (Nature Methods, 2025) for spatial transcriptomics and histopathology. The platform enables researchers to run deep learning inference on gigapixel whole-slide H&E images directly from the browser — no local Python environment or CLI required.

  • Built a Dash/React frontend that interfaces with Loki’s deep learning inference pipeline for nuclei segmentation and cell-type annotation on whole-slide histopathology images.
  • Streamed and rendered gigapixel whole-slide images interactively in the browser with color-coded cell-type overlays.
  • Integrated an LLM-powered AI chatbot for on-demand pathological interpretation of segmented cell types and tissue microenvironments.
